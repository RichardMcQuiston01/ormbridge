# Laravel example

This folder shows ormbridge converting the shared blog schema to Laravel and back.

- `ormbridge.config.json` defines two conversions: `to-laravel` and `from-laravel`.
- `models/` is generated from `../schema/schema.prisma`: Eloquent models in `app/Models/`, the `PostStatus` backed enum in `app/Enums/`, and six migrations in `database/migrations/`.
- `prisma/schema.prisma` is generated by reading `models/` back.

Run it (the config file supplies the paths and formats):

```bash
cd examples/laravel
npx ormbridge convert           # regenerate models/ and prisma/schema.prisma
npx ormbridge convert --check   # exit code 3 if a generated file is stale
```

Inside this repository, run `npm run build` once and use `node ../../dist/cli.js convert` instead of `npx ormbridge convert`. `npm run examples` regenerates every example and `npm run examples:check` verifies them.

The files are generated, so edit `../schema/schema.prisma` and rerun rather than editing them. See the [Laravel guide](../../docs/formats/laravel.md) for what is read, written and lost.
