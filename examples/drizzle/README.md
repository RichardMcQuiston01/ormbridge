# Drizzle example

This folder shows ormbridge converting the shared blog schema to a Drizzle ORM schema and back.

- `ormbridge.config.json` defines two conversions: `to-drizzle` and `from-drizzle`.
- `models/` is generated from `../schema/schema.prisma`: `schema.ts` (enums, `pgTable` tables and `relations()`) and `drizzle.config.ts` for `drizzle-kit`.
- `prisma/schema.prisma` is generated by reading `models/` back.

Run it (the config file supplies the paths and formats):

```bash
cd examples/drizzle
npx ormbridge convert           # regenerate models/ and prisma/schema.prisma
npx ormbridge convert --check   # exit code 3 if a generated file is stale
```

Inside this repository, run `npm run build` once and use `node ../../dist/cli.js convert` instead of `npx ormbridge convert`. `npm run examples` regenerates every example and `npm run examples:check` verifies them.

The files are generated, so edit `../schema/schema.prisma` and rerun rather than editing them. See the [Drizzle guide](../../docs/formats/drizzle.md) for what is read, written and lost.
