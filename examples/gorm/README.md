# GORM example

This folder shows ormbridge converting the shared blog schema to GORM structs and back.

- `ormbridge.config.json` defines two conversions: `to-gorm` and `from-gorm`.
- `models/models/` is generated from `../schema/schema.prisma`: one Go file per model plus `post_status.go` for the enum, all in `package models`.
- `prisma/schema.prisma` is generated by reading `models/` back. This step prints seven `constraint:` tag warnings, which are expected for ormbridge's own output.

Run it (the config file supplies the paths and formats):

```bash
cd examples/gorm
npx ormbridge convert           # regenerate models/ and prisma/schema.prisma
npx ormbridge convert --check   # exit code 3 if a generated file is stale
```

Inside this repository, run `npm run build` once and use `node ../../dist/cli.js convert` instead of `npx ormbridge convert`. `npm run examples` regenerates every example and `npm run examples:check` verifies them.

The files are generated, so edit `../schema/schema.prisma` and rerun rather than editing them. See the [GORM guide](../../docs/formats/gorm.md) for what is read, written and lost.
