# Sequelize example

This folder shows ormbridge converting the shared blog schema to Sequelize 6 models and back.

- `ormbridge.config.json` defines two conversions: `to-sequelize` and `from-sequelize`.
- `models/` is generated from `../schema/schema.prisma`: one TypeScript file per model (`class Post extends Model<...>` with `declare` fields and a static `initModel(sequelize)`) and an `index.ts` that exports the models and an `initModels(sequelize)` function, which initializes every model and then sets up the associations.
- `prisma/schema.prisma` is generated by reading `models/` back. It is the same schema as the shared one, apart from what Sequelize does differently (for example `created_at` and `updated_at` are Sequelize timestamps, which the application fills in, so they have no database default).

Sequelize claims no file extension (`.js` and `.ts` are too generic), so the config names `from` and `to` explicitly. The default `init` style writes TypeScript; add `"style": "define"` to a conversion for the CommonJS files `sequelize-cli` generates (`module.exports = (sequelize, DataTypes) => ...` plus an `index.js` loader).

Run it (the config file supplies the paths and formats):

```bash
cd examples/sequelize
npx ormbridge convert           # regenerate models/ and prisma/schema.prisma
npx ormbridge convert --check   # exit code 3 if a generated file is stale
```

Inside this repository, run `npm run build` once and use `node ../../dist/cli.js convert` instead of `npx ormbridge convert`. `npm run examples` regenerates every example and `npm run examples:check` verifies them.

To use the models, compile them with `tsc` (or run them with `tsx`) and give them a connection:

```ts
import { Sequelize } from 'sequelize';
import { initModels } from './models/index.js';

const sequelize = new Sequelize('sqlite::memory:');
const { User, Post } = initModels(sequelize);
await sequelize.sync();
```

The files are generated, so edit `../schema/schema.prisma` and rerun rather than editing them. See the [Sequelize guide](../../docs/formats/sequelize.md) for what is read, written and lost.
