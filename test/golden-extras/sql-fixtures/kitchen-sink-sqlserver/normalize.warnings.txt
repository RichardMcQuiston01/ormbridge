Account.labels: SQL Server has no array column type; the array was written as a JSON column.
Account.ttl: SQL Server has no interval type; the duration was written as an integer (microseconds).
GroupFriends.to_group: SQL Server rejects cascading actions that form a cycle or a second cascade path; the foreign key was written with NO ACTION.
SQL Server cannot refresh a column on update from the DDL (Account.updated_at, Session.updated_at, Group.updated_at, Membership.updated_at, Profile.updated_at, legacy_order.updated_at); the application or a trigger has to set it.
