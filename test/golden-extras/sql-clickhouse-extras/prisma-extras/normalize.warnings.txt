OrderLine.order: ClickHouse has no foreign keys; the composite key to Order (orderRegion, orderNumber) was dropped and its columns stay plain columns.
Account.email: ClickHouse has no unique constraints; the unique constraint on "email" was dropped (a ReplacingMergeTree with that column in its ORDER BY can deduplicate rows).
Account.tenant: ClickHouse has no foreign keys; the relation to Tenant was written as the plain column "tenant_id" (no constraint, no ON DELETE action).
Profile.account: ClickHouse has no foreign keys; the relation to Account was written as the plain column "account_id" (no constraint, no ON DELETE action).
Profile.account: ClickHouse has no unique constraints; the one-to-one uniqueness of "account_id" was dropped.
Document.id: the cuid() default is generated by the ORM client, not the database; the default was dropped.
Document.ulid: the ulid() default is generated by the ORM client, not the database; the default was dropped.
Document.ulid: ClickHouse has no unique constraints; the unique constraint on "ulid" was dropped (a ReplacingMergeTree with that column in its ORDER BY can deduplicate rows).
Document.short: the nanoid() default is generated by the ORM client, not the database; the default was dropped.
Document.at: ClickHouse has no stable time-of-day type; the column was written as a String ("HH:MM:SS").
Document index (title, created): the index option(s) type BTree, sort order, prefix length and operator class have no ClickHouse equivalent and were dropped.
Document index (meta): the index option(s) type Gin, sort order, prefix length and operator class have no ClickHouse equivalent and were dropped.
Document index (title, day): ClickHouse has no unique indexes; it was written as a data-skipping index (set(100)) and uniqueness is not enforced (a ReplacingMergeTree can deduplicate by ORDER BY key).
DocumentSummary: this is a database view; the schema has no SQL definition for it, so only a commented placeholder was written.
ClickHouse cannot refresh a column on update from the DDL (Order.updated_at, OrderLine.updated_at, Account.updated_at, Tenant.updated_at, Profile.updated_at, Document.updated, Scratch.updated_at); the application has to set it.
