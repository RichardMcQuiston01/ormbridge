Account.balance: the Sequelize 7 SQLite dialect has no DECIMAL type; the column was written as DOUBLE, which is not exact.
Account.labels: SQLite has no array column type; the array was written as JSON.
Account.ttl: Sequelize has no interval type; the duration was written as BIGINT (microseconds).
Session.token: Sequelize generates UUID versions 1 and 4 only; the version 7 default was written as UUIDV4.
