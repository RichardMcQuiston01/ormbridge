Account.payload: Hibernate 5 has no JSON type; the column was written as a String with the column definition jsonb, and the JSON text is yours to read and write (the hibernate-types library adds a mapping).
Account.labels: Hibernate 5 cannot map arrays; the column was written as a String with the column definition text[].
Account.ip: Hibernate 5 has no inet mapping; the column was written as a String with the column definition inet.
Session.token: Hibernate 5 generates identifiers only; the UUID is generated by the database (gen_random_uuid()).
Session.account: JPA has no setting for the onUpdate action "cascade", so it was ignored.
Session.account: Hibernate 5 knows only ON DELETE CASCADE (@OnDelete); the SET NULL action was dropped and the database default (no action) applies.
